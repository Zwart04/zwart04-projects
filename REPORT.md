# Zwart04 public rebuild

Scope: 48 public repositories owned by Zwart04. All private repositories and agenmini, zwartos, ZwartGuard, daily-apps, rakaat-counter are excluded.

## Result

34 maintained project repositories, 44 independently hosted applications. 14 source repositories are consolidated and archived only after source publication and replacement verification. No repository is deleted and original Git history is retained.

## Validation boundaries

All maintained applications have a production build and type check. Live verification checks the HTTPS homepage and referenced JavaScript/CSS assets. Representative browser checks include attribution CRUD and persistence, live public prices and portfolio persistence, WebGL compilation and errors, and decoding/selection of synthetic audio. These checks do not prove every integration or every user journey.

AI services, WhatsApp automation servers, real sensor feeds, payments, multi-user authentication and shared databases are not activated by deploying a browser workspace. Existing demonstration/local data is described in project documentation. StockGenie uses a public market feed. AudioMind processes audio locally.

## Recovery

The release `before-rebuild` contains full Git bundles for all 44 previously nonempty in-scope repositories plus SHA256 checksums. Four repositories were empty before this rebuild. Restore a bundle with `git clone <name>.bundle <directory>`. Original repositories remain available. See migration-records.json for original commit hashes and checksums.
